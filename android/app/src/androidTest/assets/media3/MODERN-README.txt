Modern video codec test fixtures

These are original synthetic FFmpeg testsrc2 animations, with no downloaded or
third-party video. Each is approximately three seconds, 320x180 at 24 fps, silent.
They are Android instrumentation assets only and are excluded from release APKs.

modern-hevc-main10.mkv: HEVC, 10-bit YUV 4:2:0 (native decoded format yuv420p10).
modern-vp9.webm: VP9, 8-bit YUV 4:2:0.
modern-av1.mkv: AV1, 8-bit YUV 4:2:0, encoded with SVT-AV1.

The supplied bytes were generated with the existing Windows mpv/FFmpeg build
in windows-prototype/runtime/mpv/mpv.exe on 2026-10-19. Encoder arguments:

Common:
--no-config --terminal=yes --end=3 --o=<output> --of=<matroska or webm>
av://lavfi:testsrc2=duration=3:size=320x180:rate=24

HEVC:
--ovc=libx265
--ovcopts=preset=ultrafast,crf=34,x265-params=pools=1:frame-threads=1:log-level=error
Source adds ,format=yuv420p10le to the lavfi expression.

VP9:
--ovc=libvpx-vp9
--ovcopts=deadline=realtime,cpu-used=8,crf=40,b=0,threads=1

AV1:
--ovc=libsvtav1
--ovcopts=preset=12,crf=40,svtav1-params=lp=2:loglevel=0

generate-modern-fixtures.sh provides equivalent normal FFmpeg commands. Encoder
versions and muxer timestamps may change regenerated bytes; MODERN-SHA256SUMS
identifies the exact checked-in fixtures used by the instrumentation tests.

ModernCodecPlaybackTest additionally uses the existing H.264 gesture-av.mp4.
Tests require an unlocked device, wait for a real rendered frame, copy pixels
from the Surface with PixelCopy, check colored output, codec identity, timeline
advance and normal EOF. A separate AV1 run forces the server software hint.
These small fixtures establish decoding/rendering functionality; they do not
measure 4K/8K speed, HDR accuracy, DRM playback or every codec profile.
