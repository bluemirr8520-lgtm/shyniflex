#### :information_source: New `allstorage` APK

The `api29` APK has been removed and replaced with `allstorage`, which uses the "manage external storage" permission to allow unrestricted file access without having to downgrade the API level.
It will stay separate and not be shipped to Google Play.

### :arrow_down_small: Which APK do I download? :arrow_down_small:

You generally want to get **`arm64-v8a`**. Try `armeabi-v7a` for old devices. Or `x86` otherwise.
If you are unsure then the `universal` APK will work everywhere.

**Note**: Android TV is supported, but only available on F-Droid or by installing the APK manually using e.g. [Downloader](https://play.google.com/store/apps/details?id=com.esaba.downloader).
