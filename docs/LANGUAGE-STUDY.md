# 어학 학습

홈 하단 **더보기 → 어학 학습**에서 기본 배속과 자막 위치를 설정합니다.
영상 재생 중 **재생 설정 → 어학 학습**에서 문장 이동, 문장 반복, A–B 반복,
원문·번역 자막을 사용할 수 있습니다.

## 반복 구간의 어휘·문법

1. 영어 텍스트 자막을 선택합니다. 자막 파일을 직접 불러오거나
   **원문·번역 자막**에서 영어 트랙을 선택할 수 있습니다.
2. **문장 반복** 또는 **A 지정 → B 지정**으로 학습 구간을 정합니다.
3. **어휘·문법**을 누르면 구간의 원문, 기본 어휘·숙어 뜻, 문법 패턴을 확인합니다.
   반복 구간을 지정하지 않았다면 현재 표시되는 문장을 사용합니다.

설명은 한국어이며 앱에 포함된 영어 기본 사전과 문법 규칙으로 처리합니다.
추가 계정·AI 모델 다운로드·외부 분석 서비스가 필요하지 않습니다.
서버 자막이 필요할 때만 기존 영상 서버에서 자막을 불러옵니다.
기본 뜻과 형태 설명이므로 문맥 번역이나 모든 단어·문법 분석을 제공하지는 않습니다.
등록되지 않은 단어는 별도로 표시하며 뜻을 추측하지 않습니다.

텍스트로 제공되는 내장 자막도 사용할 수 있습니다. 현재 문장은 재생 엔진의
텍스트 자막을 이용할 수 있지만, A–B 전체 구간에는 시간 정보가 있는 자막이
필요합니다. 서버에서 추출할 수 없으면 영어 자막 파일을 직접 불러오세요.
이미지 자막의 글자를 읽는 OCR은 포함되어 있지 않습니다.

재생 부담을 줄이기 위해 버튼을 누를 때만 분석하며, 현재 영상의 최근 결과
16개를 메모리에서 재사용합니다. 앱을 벗어나거나 영상이 바뀌면 지웁니다.
한 번에 자막 60개·4,000자, 어휘 24개·문법 패턴 8개까지 표시합니다.
일부만 표시되었다는 안내가 나오면 반복 구간을 짧게 나눠 주세요.

모바일에서는 본문을 스크롤할 수 있고, TV에서는 리모컨 위·아래로 본문을
이동합니다. 끝까지 내려가면 **닫기**로 이동합니다.
