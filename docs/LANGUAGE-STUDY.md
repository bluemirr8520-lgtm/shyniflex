# 어학 학습

홈 하단 **더보기 → 어학 학습**에서 기본 배속과 자막 위치를 설정합니다.
영상 재생 중 **재생 설정 → 어학 학습**에서 문장 이동, 문장 반복, A–B 반복,
원문·번역 자막을 사용할 수 있습니다.

- **이전 문장·다음 문장**: 시간 정보가 있는 자막의 문장 사이로 이동합니다.
- **문장 반복**: 현재 자막 문장을 반복합니다.
- **A 시작점 지정 → B 끝점 지정**: 직접 정한 구간을 반복합니다.
- **반복 해제**: 지정한 반복 구간을 해제합니다.
- **원문·번역 자막**: 보조 자막을 선택하고 표시 위치를 정합니다.
- **배속**: 학습에 맞게 재생 속도를 조절합니다.

문장 이동·문장 반복에는 시간 정보가 있는 텍스트 자막이 필요합니다.
지원되지 않는 내장 자막은 A–B 반복을 이용하거나 자막 파일을 불러와 주세요.
