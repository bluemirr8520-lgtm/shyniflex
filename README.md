# shyniflex

Shyni 서버용 미디어 플레이어입니다. Android 앱은 MPV를 사용하며 휴대폰·태블릿·Android TV와 Android 8.0 이상을 지원합니다. `webos/`에는 LG TV용 HTML5 클라이언트가 함께 있습니다.

## PLEXMINI (Android)

Plex Media Server용 독립 앱입니다. 패키지 ID는 `io.mirr.shyniflex.plex`이며 기존 Shyni 앱과 한 기기에 함께 설치할 수 있습니다.

**다른 기기의 업데이트**는 [PLEXMINI 1.0.4 설치 파일](https://github.com/bluemirr8520-lgtm/shyniflex/releases/download/plexmini-v1.0.4/PLEXMINI-1.0.4.apk)부터 지원합니다. 1.0.3 이하를 사용 중인 기기는 이 파일을 기존 앱 위에 한 번 설치하세요. 이후 앱을 실행하면 로그인 전에도 새 버전을 확인하고 내려받습니다. Android 설치 화면에서 **업데이트**를 누르면 로그인과 설정을 유지합니다. 처음에는 Android에서 PLEXMINI의 앱 설치를 허용해야 할 수 있습니다. 직접 확인하려면 로그인 화면의 **업데이트 확인**, 휴대폰의 **더보기 → 업데이트**, TV 왼쪽 메뉴의 **업데이트**를 사용하세요.

1. 첫 화면의 **아이디·비밀번호로 로그인**에서 Plex 계정에 로그인합니다. 앱이 등록된 서버를 찾아 한 대면 바로 연결하고, 여러 대면 서버 이름을 표시합니다. 주소를 알고 있다면 첫 화면의 **Plex 서버 주소**에 입력할 수 있습니다. 연결 후에는 휴대폰의 **더보기 → 서버 연결** 또는 TV 왼쪽 메뉴의 **서버 연결**에서 다른 서버를 선택할 수 있습니다.
2. Android TV에서는 **TV 연결 코드 사용**을 누른 뒤 휴대폰이나 PC의 [Plex 기기 연결 페이지](https://plex.tv/link/)에 코드를 입력할 수 있습니다. 서버 토큰이 있으면 **서버 주소와 토큰으로 연결**을 사용할 수 있습니다.
3. 휴대폰에서는 **홈 · 검색 · 라이브러리 · 더보기**, Android TV에서는 왼쪽 메뉴로 이동합니다. 홈에서 이어보기와 라이브러리별 최근 추가 작품을 확인하고, 라이브러리에서 정렬과 시청 상태 필터를 바꿀 수 있습니다. 작품 상세에서 시즌과 회차, 원본 화질, 파일 정보와 출연진을 확인합니다. 이어보기 위치와 시청 상태는 연결한 Plex 서버에 기록됩니다.

이 버전은 Plex의 단일 파일 원본을 직접 재생합니다. 여러 파일로 분할된 작품 및 Plex 서버 트랜스코딩은 지원 범위에서 제외됩니다. 빌드 환경을 아래 Android 안내대로 준비한 뒤 `Build-Android.cmd -Plex`를 실행하면 서명된 통합 APK가 `android/build/plex-app/outputs/apk/release/app-release.apk`에 생성됩니다.

## LG webOS

webOS판은 앱 ID `io.mirr.shyniflex.webos`로 Android판과 같은 Shyni 로그인·2단계 인증·라이브러리·검색·이어보기·재생 티켓·시청 기록 API를 사용합니다. 구형 TV에서는 서버의 최대 1080p 호환 변환을 기본으로 사용해 원본 코덱이 TV 재생기를 중단시키는 일을 줄입니다. 포스터와 자막은 짧은 수명의 인증 티켓 또는 인증 요청으로 받아 토큰을 URL에 노출하지 않습니다.

설치·빌드·서버 요구사항은 [webOS 안내](webos/README.md)를 참고하세요. 설치 파일은 [ShyniFlex webOS 1.0.4 릴리스](https://github.com/bluemirr8520-lgtm/shyniflex/releases/tag/webos-v1.0.4)에서 받을 수 있습니다.

## Android

한국 작품으로 확인된 드라마·영화는 자막을 기본으로 끄고 시작합니다. 필요할 때 재생 화면의 **자막** 메뉴에서 서버·내장·불러온 자막을 직접 선택하거나 파일을 추가할 수 있습니다. 같은 영상을 재생하는 동안에는 선택을 유지하며, 다른 영상이나 다음 회차는 기본값으로 시작합니다. 제작 국가 정보를 먼저 사용하고, 국가 정보가 없으면 원어를 확인합니다.

홈 이어보기에서 제작 국가·원어 정보가 빠진 경우에는 재생 시작 후 작품 상세를 별도로 확인해 자막 기본값을 보완합니다. 두 정보가 모두 없을 때는 실제 선택되어 재생 중인 음성이 한국어이면 자막을 기본으로 끕니다. 따라서 제작 국가·원어가 없는 해외 작품의 한국어 더빙도 기본 끄기가 적용될 수 있습니다. 음성 언어만으로 제작 국가를 저장하거나 한글 제목으로 국가를 추측하지 않으며, 선택된 음성 언어도 확인되지 않으면 기존 기본값을 유지합니다. 영상은 조회를 기다리지 않고 계속 재생되며, 사용자가 직접 선택한 자막은 변경하지 않습니다.

홈의 최근 추가 포스터를 누르면 작품의 포스터·기본 정보·줄거리가 회차 목록보다 먼저 표시됩니다. 상세 화면에서 이어볼 영상이 있으면 **이어보기** 왼쪽에 **처음부터 보기**를 표시해 같은 영상을 처음부터 재생할 수 있습니다.

재생 화면의 **자막 → 자막 파일 불러오기**에서 기기에 저장한 SRT·ASS/SSA·VTT·SMI/SAMI·TTML/DFXP 자막을 추가할 수 있습니다. **웹에서 자막 검색**은 작품명·회차로 검색어를 준비하며, Android TV에서는 휴대폰 검색용 QR도 제공합니다. 불러온 자막은 해당 영상에 저장해 MPV와 ExoPlayer에서 공통 자막 설정으로 표시합니다. [수동 자막 사용·온라인 서비스 연동 안내](docs/MANUAL-SUBTITLES.md)를 참고하세요.

WMV/ASF의 VC-1·WMA Pro와 AVI·FLV·MPEG-TS 같은 일반 영상 형식은 MPV의 FFmpeg 디코더로 재생합니다. 서버가 해당 형식에 호환용 리먹스·오디오 변환을 제안해도 원본 재생 티켓을 받아 직접 재생하며, 원본 접근 권한과 명시적인 영상 변환은 그대로 적용합니다. ExoPlayer를 저장해 둔 경우에도 이 형식은 MPV로 바로 엽니다.

ExoPlayer는 서버의 외부 텍스트 자막과 정확히 식별된 단일 내장 mov_text·SRT/SubRip 자막을 지원합니다. 내장 자막은 서버의 스트림 번호·형식, MPV의 실제 트랙, ExoPlayer의 추출 형식을 대조한 뒤 표시합니다. 내장 SRT의 이어보기·탐색은 앞 구간에서 시작한 긴 자막이 누락되지 않도록 같은 위치에서 MPV로 재생합니다. 다중 내장·이미지 자막과 ExoPlayer가 읽지 못하는 형식도 MPV를 사용합니다.

첫 로그인 화면의 서버 주소는 빈칸이며 사용자가 직접 입력합니다.

앱을 실행하면 새 버전을 확인하고, 업데이트가 있으면 내려받아 Android 설치 화면으로 안내합니다. 설치 출처 허용과 최종 설치 확인은 Android에서 진행합니다. 설치를 취소하면 같은 실행 중에 반복해서 설치 화면을 열지 않습니다.

휴대폰·태블릿에서 계속 시청 포스터를 좌우로 밀면 배경 그림도 같은 진행률로 이동합니다. 손을 놓은 뒤 관성 스크롤까지 따라가며, 멈추면 선택된 포스터의 배경으로 정착합니다. 배경의 그라데이션과 글자 위치는 유지합니다.

재생할 원본 해상도가 한 종류이면 바로 재생하고, 두 종류 이상일 때만 해상도를 선택합니다. 해상도 선택의 **자동** 항목은 없으며, 같은 해상도의 파일이 여러 개면 서버가 정한 우선 파일을 재생합니다.

정상 재생을 마치면 목록의 **보았음** 표시와 계속 시청 목록을 즉시 갱신합니다. 기존 95% 시청 완료 기준은 유지하며, 서버 저장은 별도로 마무리합니다. 저장에 실패하면 임시 완료 표시를 해제하고 오류를 안내합니다.

재생 중 **설정 → 영상 보정**에서 영상 자체의 **밝기·대비(농도)·채도**를 조절합니다. **프리셋 불러오기·관리**에는 원본·부드럽게 및 아래 프리셋가 있으며, **현재 설정 저장**으로 사용자 프리셋을 이름 붙여 최대 20개까지 기기에 보관할 수 있습니다. 저장한 값은 적용·덮어쓰기·이름 변경·삭제할 수 있고, 마지막으로 적용한 보정은 다음 재생에도 유지됩니다. **원본으로 되돌리기**는 영상 보정만 해제합니다. 기기 화면 밝기, 자막 색상·크기, 화면 비율과 재생 엔진 선택은 바꾸지 않습니다.

같은 목록에서 선명한 영상·영화·스포츠·게임·밝은 공간·어두운 공간·필름메이커도 선택할 수 있습니다. 목록은 별도 제목과 부가 설명 없이 프리셋 선택 항목부터 표시합니다. 비슷한 항목인 밝게·시네마·선명하게·표준은 목록에서 정리했으며, 이전에 적용한 값과 사용자 프리셋은 보존합니다. **필름메이커**를 선택하면 밝기·대비·채도를 모두 0으로 적용해 원본 색감을 유지하고, 선택한 이름도 기기에 저장합니다. 원본 표현을 보존하는 [공식 모드의 취지](https://filmmakermode.com/about/)를 참고한 앱 내 설정으로, TV의 실제 화면 모드·색온도·움직임 보정이나 인증 기능은 변경하지 않습니다.

1.0.98부터 SDR 영상은 ExoPlayer에서도 밝기·대비·채도를 직접 적용합니다. 효과가 없던 영상에서 처음 보정을 켤 때는 현재 위치·일시정지·배속을 유지해 한 번 재준비하고, 그 뒤의 값 변경은 일시정지 중에도 화면에 바로 반영합니다. HDR·Dolby Vision 영상의 보정은 MPV를 사용하며 저장한 재생 엔진 선택은 유지합니다. 원본으로 되돌리면 색 보정을 해제합니다. TV에서는 위아래로 조절 항목을 이동하고 좌우로 값을 바꿉니다.

**설정 → 재생 엔진**에서 자동·MPV·ExoPlayer를 선택하면 현재 영상에 바로 적용하며 재생 위치·일시정지·배속과 영상 보정값을 유지합니다. SDR 영상에서는 ExoPlayer로 전환해도 보정을 해제하지 않습니다. HDR·Dolby Vision 보정, 변환 영상이나 지원을 확인할 수 없는 영상·자막은 MPV로 재생하고 현재 엔진을 표시합니다. 이름 붙여 저장한 사용자 프리셋도 유지됩니다.

휴대폰·태블릿에서는 재생을 시작하기 전 목록 화면의 방향을 기억했다가 재생 종료 후 같은 방향으로 복원합니다. 복귀 직후 기기를 들고 있는 각도 때문에 목록이 다시 회전하지 않도록 잠시 방향을 유지하고, 기기 자세가 복원된 방향과 맞거나 앱을 벗어나면 원래 화면 회전 설정으로 돌아갑니다. 재생 중 가로 방향 전환과 Android TV의 방향 동작은 기존대로 유지합니다.

Android TV에서는 **QR로 로그인 → QR 코드 만들기**를 선택한 뒤 휴대폰 shyniflex 앱으로 코드를 엽니다. 휴대폰에서 같은 서버에 로그인하고 **TV 연결 승인**을 눌러야 TV 로그인이 진행됩니다. 두 기기 모두 1.0.46 이상이 필요합니다. 휴대폰 QR 읽기 기능에서 링크를 shyniflex 앱으로 여는 기능이 필요하며, 브라우저 승인 페이지를 새로 제공하는 기능은 아닙니다. TV에서 서버 주소를 바꾸거나 직접 입력으로 전환하거나 로그인 화면을 벗어나면 대기 중인 연결을 취소합니다. 만료되면 새 코드를 만들 수 있습니다.

휴대폰·태블릿에서 **더보기 → 잠긴 라이브러리**를 누르면 PIN 입력창을 직접 엽니다. 사전 잠금 상태 조회가 실패해도 입력창을 열 수 있으며, 라이브러리 선택창에도 잠금 해제 항목을 제공합니다. 서버에서 PIN 사용을 꺼 둔 경우에는 설정 안내를 표시합니다. PIN 창은 키보드가 열린 작은 화면에서도 확인 버튼에 접근할 수 있으며, 제출하면 키보드를 닫고 처리 중 상태를 표시합니다. 초기 잠금 해제 요청의 대기 시간을 제한하고, PIN·로그인·네트워크 오류를 구분해 다시 시도할 수 있도록 안내합니다.

휴대폰·태블릿·Android TV 홈 화면은 **시네마 천국·포스터 중심 OTT·호텔 라운지** 중에서 고를 수 있습니다. 시네마 천국은 에스프레소 배경과 아이보리·황동빛 강조색, 포스터 중심 OTT는 어두운 배경과 민트 강조색, 호텔 라운지는 밝은 아이보리와 차분한 황동빛을 기본으로 사용합니다. 스타일에 따라 작품 소개와 포스터의 크기·간격, 제목 글꼴과 아이콘의 선 굵기가 함께 바뀝니다. 홈·검색·라이브러리·설정과 재생 조작에는 둥근 선형 아이콘을 사용합니다.

휴대폰·태블릿의 **더보기 → 화면 스타일**, Android TV의 **사이드바 → 화면 스타일** 또는 홈 오른쪽 위 팔레트 버튼에서 **화면 스타일 · 색상**을 엽니다. 스타일과 배경색을 고른 뒤 **적용**하면 저장됩니다. 배경색은 팔레트·RGB 조절 또는 색상 코드(`#RRGGBB`)로 지정할 수 있으며, 스타일별로 따로 저장되어 앱을 다시 열어도 유지됩니다. 기존에 저장한 배경색은 시네마 천국에 이어서 사용합니다. 선택한 배경색에 맞춰 메뉴와 재생 조작의 글자·아이콘·강조색 대비를 자동으로 조정합니다.

라이브러리는 선택한 표시 종류의 전체 작품을 보여 줍니다. 정렬 메뉴는 Shyni 서버처럼 영화는 제목·추가된 날짜·연도·출시일·평점, TV 쇼는 제목·추가된 날짜·최근 에피소드, 시즌은 제목·추가된 날짜, 에피소드는 최근 에피소드·제목·추가된 날짜을 제공합니다. 제목·연도·출시일은 선택한 정렬 항목을 다시 눌러 방향을 바꾸며, 추가된 날짜·최근 에피소드·평점은 서버와 같은 내림차순을 사용합니다. 서버 응답의 정렬 순서를 유지한 채 앱에서 다음 페이지를 불러옵니다. 시리즈 포스터에서 첫 시즌의 썸네일 회차 목록을 바로 열고 같은 화면에서 시즌을 바꿉니다. 작품 안의 **해상도** 폴더로 원본 4K·1080p·720p 등의 버전을 선택하며, 이 분류는 서버 파일을 이동하지 않습니다. 같은 해상도의 파일이 여러 개면 서버가 정한 우선 버전을 사용합니다.

## 설치와 사용

설치 파일은 위 APK 링크의 `shyniflex-new.apk`(1.0.101, 빌드 102)입니다. 정식 패키지는 `io.mirr.shyniflex.renewed`이며, 같은 패키지와 공식 서명으로 업데이트하면 로그인과 설정을 유지합니다.

1. APK를 Android 기기에 설치합니다.
2. Shyni 서버의 HTTPS 주소와 사용자 이름·비밀번호를 입력해 로그인합니다. 2단계 인증을 사용하는 경우 인증 코드를 입력합니다.
3. 라이브러리에서 영화 또는 회차를 선택해 재생합니다. 모바일 하단 또는 TV 사이드바의 **검색**으로 여러 라이브러리의 제목을 찾고 작품을 열 수 있습니다.
4. 재생 화면 하단의 **CC(자막 선택)** 버튼으로 자막을 고릅니다. **설정 → 자막 → 자막 모양 → 세로 쓰기**에서 세로 자막을 켭니다. **자막 모양 → 세로 자간**에서 글자 간격을 선택하면 즉시 적용되고 다음 재생에도 유지됩니다.
5. **설정 → 자막 → 자막 글꼴**에서 **시스템 기본** 또는 직접 가져온 글꼴을 고릅니다. **폰트 파일 추가**로 TTF/OTF 파일을 가져옵니다.
6. 자막을 길게 누른 뒤 끌면 위치가 바뀝니다. 손을 떼면 저장하고, 화면 밖으로는 벗어나지 않습니다. TV에서는 같은 설정의 **자막 위치** 메뉴를 사용합니다.

이어보기는 부분 시청을 끝낼 때 최종 위치 저장을 최대 4초 기다린 뒤 갱신하며, 늦게 저장이 완료돼도 홈을 다시 불러옵니다. 진행률 저장의 일시적인 통신 오류는 요청당 5초 한도로 최대 3번 시도합니다. 이어보기 조회가 실패하면 오류를 표시하고, 같은 서버·계정에서 여전히 접근 가능한 목록만 유지합니다. 로그인 변경·권한 거부·스포일러 잠금 뒤에는 이전 비공개 항목을 재사용하지 않습니다. 표시 여부는 서버가 결정하며, 스킵 후에도 이어보기를 표시하려면 저장된 재생 위치를 인정하는 서버가 필요합니다. 실제 시청 누적 시간은 재생한 만큼 별도로 전송합니다. 앱 프로세스가 종료될 때까지 저장에 성공하지 못한 요청을 영구 보관하는 기능은 포함하지 않습니다.

작품 상세의 이어보기 대상이나 회차 시청 기록에서 서버가 회차 정체성 오류를 보내더라도, 접근이 허용된 시즌·회차 목록을 표시합니다. 조회에 실패한 시청 기록은 기존 상태를 유지하며, 다른 묶음에서 정상 조회한 기록은 반영합니다. 실제 시즌·회차 목록 조회와 재생 요청의 오류는 그대로 안내합니다.

저장된 로그인이 있으면 홈 화면을 먼저 표시하고 계정 검증과 스포일러 상태 조회를 병행합니다. 일반 이어보기·최근 추가 목록은 비공개 목록이나 선택 기능의 응답을 기다리지 않고, 확인된 라이브러리 범위에서 표시합니다. 홈을 불러오는 중에도 라이브러리 선택과 재생을 할 수 있습니다.

이어보기와 최근 추가 목록은 각 응답이 도착하는 대로 따로 표시합니다. 최근 추가 목록을 불러오는 동안에도 이어보기 카드를 선택할 수 있습니다. 이어보기 영역은 빈 기록·불러오는 중·오류를 구분해 표시하고, 오류에는 다시 시도 버튼을 제공합니다. 잘못된 응답 구조를 빈 기록으로 간주하지 않으며, 같은 계정의 기존 목록만 권한 범위 안에서 유지합니다.

홈 이어보기는 제목·회차·소개와 **이어보기 버튼**을 큰 작품 배경 위에 표시합니다. 배경 사진은 썸네일 줄 아래까지 이어지고 아래로 갈수록 선택한 앱 배경색으로 부드럽게 옅어집니다. 큰 배경은 이어보기 목록의 작품을 6초마다 순환하며, 마지막 작품 다음에는 처음 작품으로 돌아갑니다. 앱이 전경이고 배경 영역이 화면에 보일 때만 자동 전환하며 현재 초점이나 포스터 줄의 스크롤 위치를 옮기지 않습니다. 목록에서 작품에 초점을 옮기거나 배경이 자동으로 바뀌면 상단 정보와 이어보기 버튼의 대상이 함께 바뀝니다. 이어보기 버튼은 현재 배경에 표시한 작품을 실제 시청 위치에서 재생합니다. 시간 정보가 없으면 남은 시간을 추측하지 않습니다.

이어보기의 회차 목록과 영화·회차 혼합 목록은 **16:9 가로 썸네일**, 영화만 있는 목록은 **2:3 세로 포스터**를 사용합니다. 서버가 제공한 회차 스틸(`thumb_url`), 작품 포스터(`poster_url`), 배경 이미지(`art_url`)를 각각 보존하며, 제공하지 않은 이미지는 있는 이미지로 대체합니다. 카드 아래에는 작품명과 시즌·회차·회차 제목을 표시합니다. 카드나 이어보기 버튼을 누르면 해당 작품을 시청하던 위치에서 바로 재생하고, 카드를 길게 누르면 시청 상태를 변경합니다. 아래 포스터 줄 자체는 끝이 있는 유한 가로 목록으로 유지하며, 배경·정보 영역의 순환과 구분합니다. 최근 추가됨 목록과 스포일러 잠금에 따른 표시 규칙은 유지합니다.

보았음 상태는 작품 포스터와 회차 썸네일 위에 표시합니다. 홈·라이브러리·회차 목록의 포스터를 **길게 누르면 보았음 / 보지 않음 / 취소**만 표시하는 작은 팝업을 엽니다. 팝업에는 현재 상태의 체크 아이콘을 표시하지 않습니다. 시리즈·시즌의 보았음·보지 않음은 전체 회차에 적용하며, 접근이 허용된 회차를 한 번에 최대 500개까지 변경합니다. 500개를 초과하면 변경을 시작하지 않습니다. 일부 회차 변경에 실패하면 성공한 회차 수를 안내하며, 이미 성공한 변경은 서버에 남습니다. 시리즈·시즌의 전체 시청 표시는 모든 변경이 성공한 뒤 현재 앱 세션에서 유지합니다.

정상 재생으로 **전체 영상 길이의 95% 지점**을 통과하면 서버에 보았음으로 저장하고 포스터 표시를 갱신합니다. 스킵이나 이어보기 복원으로 95% 뒤에 도착한 것만으로는 완료 처리하지 않습니다. 탐색 뒤 실제 재생을 이어가 자연 종료에 도달한 경우에도 완료를 허용합니다. 이 구분을 서버의 자동 완료 판정에도 적용하려면 `completion_eligible` 진행률 필드를 지원하는 Shyni 서버가 필요합니다. 변환 재생도 원본 전체 영상의 위치를 기준으로 합니다. MPV의 실제 종료 상태를 확인하면 서버 저장 응답을 기다리지 않고 재생창을 닫아 **재생을 시작한 화면으로 돌아갑니다**. 이전 라이브러리·회차 화면과 탐색 위치를 유지하며, 홈 이어보기에서 시작했다면 홈으로 돌아갑니다. 끝으로 직접 스킵해 닫힌 경우에는 이어보기 위치만 저장합니다. 파일 끝 이상으로 저장된 미완료 영상은 다음에 누르면 처음부터 재생합니다. 완료 기록은 별도 작업에서 저장하고, 늦게 저장돼도 복귀한 화면의 시청 상태와 이어보기를 갱신합니다. 95% 지점에서 일시정지한 영상과 재생 오류는 창을 유지합니다. 직접 뒤로 나간 경우에도 이전에 열었던 화면으로 돌아갑니다.

라이브러리 선택 화면의 **스포일러 라이브러리 열기**에서 서버의 PIN을 입력합니다. 현재 로그인한 Shyni 서버에 등록되고 접근이 허용된 비공개 영화·시리즈 라이브러리(View)를 표시하며, 기존 계정 로그인과 서버의 접근 권한이 필요합니다. **스포일러 라이브러리 잠금**으로 다시 잠글 수 있습니다. 잠금 해제 시 입력한 PIN은 현재 앱 프로세스의 임시 문자 배열에만 보관합니다. PIN을 디스크·로그·Intent에 저장하지 않으며, 잠금 해제 권한도 앱 메모리에서만 유지합니다. 앱이 백그라운드로 전환되거나 직접 잠그면 임시 PIN을 지우고 다시 잠급니다.

스포일러 재생 화면이 전면에 있는 동안에는 일시 정지나 재생 설정 창을 열어 둔 상태도 포함해, 서버 권한이 만료되기 전에 기존 `/spoiler/client/unlock`으로 다시 인증합니다. 기존 영상과 자막을 유지하며 새 권한과 재생 티켓을 준비하고, 준비가 끝나면 바로 직전의 재생 위치·일시정지 상태·트랙·배속을 유지해 한 번만 전환합니다. 갱신에 불필요한 이어보기 조회와 중복 티켓·자막 조회를 줄입니다. 서버가 이전 권한을 폐기하거나 새 영상 데이터를 준비하는 동안에는 잠시 멈출 수 있습니다. 재인증으로 유효한 권한을 다시 받지 못하면 기존 권한의 만료를 넘겨 재생을 허용하지 않습니다. 직접 잠그거나 권한이 취소되거나 계정이 바뀌면 다시 잠급니다. 재생 화면을 떠난 뒤 서버가 정한 시간이 지나면 PIN을 다시 입력해야 합니다. 서버 코드·설정은 변경하지 않습니다.

스포일러 라이브러리의 **이어보기는 잠금을 해제한 동안에만** 표시합니다. 다시 잠그거나 권한이 만료되거나 앱이 백그라운드로 전환되면 비공개 포스터·상단 작품 정보·열려 있던 시청 상태 선택창을 즉시 숨기고, 일반 라이브러리의 이어보기는 유지합니다. 다시 잠금을 해제하면 서버의 시청 기록을 새로 불러옵니다. 잠금은 서버의 시청 기록을 삭제하지 않습니다. 공개·비공개 목록의 항목이 섞여 오면 확인된 라이브러리에 맞게 걸러내며, 같은 작품의 중복 응답은 한 번만 표시합니다.

스킵은 두 번 탭 또는 가로 스와이프로 조작합니다. 뒤로 이동하면 영상 왼쪽에 **10초<**, 앞으로 이동하면 오른쪽에 **10초>**와 같은 작은 표시가 나타납니다. 표시는 시스템 바와 화면 잘림 영역의 안쪽에 배치합니다. 스와이프 중에는 시작 위치부터 실제로 이동한 시간을 표시하고, 영상의 처음·끝에서 이동이 제한되면 그 시간에 맞춰 표시합니다. 탐색용 중앙 시계·진행 막대는 표시하지 않습니다. 밝기·음량은 기존 중앙 표시를 사용합니다. 스킵·밝기·음량·자막 이동 제스처 중에는 컨트롤이 숨겨집니다. 화면을 한 번 탭하면 컨트롤을 표시하거나 숨깁니다. 상단 **잠금** 버튼도 컨트롤과 함께 표시됩니다. 잠긴 화면을 한 번 탭하면 **해제** 버튼이 나타납니다.

하단 **이전 영상·다음 영상** 아이콘은 **현재 파일이 바로 들어 있는 실제 폴더가 같은 영상**으로만 이동합니다. 서버가 제공한 파일 경로로 같은 폴더임이 확인되어야 하며, 이동 대상이나 경로를 확인할 수 없으면 해당 아이콘을 비활성화합니다. 같은 폴더 안에서 영화는 라이브러리·검색 목록 순서, 시리즈는 시즌·회차 순서를 기준으로 이동하며, 한 작품에 묶인 파일은 서버의 파일 순서를 우선합니다. 끝에서 처음으로 순환하지 않습니다. 이동한 영상은 **0초부터** 시작하고, 선택한 배속·변환·자막 모양 설정과 일시정지 상태를 유지합니다.

서버가 인트로·크레딧의 시작·끝 구간 정보를 제공한 영상에서는 해당 구간에 **인트로 건너뛰기** 또는 **크레딧 건너뛰기** 버튼이 나타납니다. 누르면 그 구간의 끝으로 이동하며 일시정지 상태를 유지합니다. 이 기능에는 서버의 구간 마커가 필요합니다.

하단 **배속** 버튼에서 0.25~4배속을 선택하며, 선택한 속도는 다음 재생에도 유지됩니다. **화질** 버튼을 누르면 작은 선택창에서 **원본·1080p·720p·480p**를 고릅니다. TV 선택창의 폭은 360dp입니다. 변환은 현재 재생 중인 같은 파일을 서버에서 처리하며, 시청 위치와 일시정지 상태를 유지합니다. 비트레이트는 서버가 해당 해상도에 맞춰 결정하므로 실제 데이터 사용량은 원본과 서버 설정에 따라 달라집니다. 서버에 영상 인코더가 있어야 하고 계정의 변환 권한이 필요합니다. 화질과 배속은 재생 설정에서도 조절할 수 있습니다.

계정 비밀번호와 일회용 인증 코드는 저장하지 않습니다. 로그인 세션만 Android Keystore를 이용해 암호화해 저장합니다.

재생 준비 오류에는 재생 방식 확인·티켓 발급·자막 정보·이어보기 위치 조회 중 실패한 단계를 표시합니다. 서버가 재생을 허용한 파일은 진행률의 특정 회차 식별 오류 때문에 폐기하지 않고 카드에 남아 있는 시청 위치로 시작합니다. 서버의 회차 번호가 누락된 경우에는 목록에서 받은 실제 파일 ID와 같은 라이브러리 문맥으로 정식 스트림 티켓을 요청해 원본 재생을 시도합니다. 이 요청에도 서버의 파일 소속·시청 권한·동시 스트림 검사가 적용됩니다.

## 재생과 자막

### Android TV 전용 화면과 리모컨

TV 기기에서는 전용 홈·라이브러리·상세 화면과 큰 재생 버튼을 사용합니다. TV 여부는 Android의 기기 모드로 구분하므로, 휴대폰과 큰 화면 태블릿은 기존 모바일 화면을 유지합니다. 리모컨 초점은 화면 색상에 맞춘 강조색 테두리로 표시하며, 홈 목록과 라이브러리·상세 화면은 탐색 위치를 보존합니다.

- TV 사이드 메뉴에는 홈·라이브러리별 항목·새로고침·계정을 표시합니다. 라이브러리를 바로 선택할 수 있으며, 잠긴 비공개 항목은 이름을 노출하지 않고 잠금 해제 메뉴를 제공합니다. 잠금 해제 후에는 **스포일러 잠그기** 항목으로 즉시 다시 잠글 수 있습니다. 현재 메뉴와 리모컨 초점은 같은 색의 얇은 단일 하이라이트로 표시합니다.
- TV 홈은 따뜻한 영화관 테마의 작품 배경과 **계속 시청** 포스터를 연결하고, 최근 추가 목록은 선택한 앱 배경색 위에 표시합니다. 포스터는 2:3 세로 비율을 사용하며, 리모컨 초점은 얇은 강조색 외곽선으로 구별합니다. 모바일 홈은 화면 너비에 맞춘 작품 배경과 가로 스크롤 포스터 목록을 사용합니다.
- TV 재생 화면은 하단 왼쪽의 이전·뒤로 탐색·재생·앞으로 탐색·다음 버튼과 오른쪽 설정 버튼을 사용합니다. 재생 설정은 세로 목록이며, 화면 크기에서 맞춤·채움·늘림을 직접 선택합니다. TV에서는 MPV 영상 출력에 종횡비 유지와 잘라내기 값을 적용하며, 110%·125%·150% 확대도 선택할 수 있습니다. 선택한 크기는 다른 영상·앱 재실행·출력 화면 재연결 후에도 유지합니다. 직접 크기를 바꾸면 선택한 모드를 약 2초간 표시합니다.
- 홈·라이브러리: 방향키로 이동하고 확인 버튼으로 선택합니다. 이어보기 카드는 바로 재생하며, 최근 추가된 작품은 상세 화면을 엽니다.
- 시리즈·시즌 포스터 오른쪽 위의 원형 숫자는 미시청 편수입니다. 서버의 전체 회차 목록과 완료 기록을 대조하며, 부분 시청한 회차도 미시청 편수에 포함합니다. 편수는 화면 표시 후 뒤에서 계산하고, 0편이거나 조회에 실패하면 배지를 숨깁니다. 동시에 두 작품까지만 조회하며, 새로고침·재생 복귀 시 다시 계산합니다.
- 시청 상태: 카드에서 메뉴 버튼 또는 확인 버튼을 길게 누릅니다. 상세 화면의 **시청 상태** 버튼도 사용할 수 있습니다. TV는 작은 선택창에서 취소에 먼저 초점을 두며, 창을 연 확인 버튼의 반복·해제 입력으로 상태가 바뀌지 않습니다. 변경할 상태로 이동한 뒤 확인 버튼을 새로 눌러 적용합니다.
- 라이브러리는 **표시 종류·정렬 기준·정렬 방향**을 선택합니다. 별도의 시청 상태·장르·연도·연대 필터는 제공하지 않습니다. 정렬은 전체 목록에 적용한 뒤 페이지를 나누며, 휴대폰·태블릿의 기존 검색은 유지합니다.
- 재생 화면의 조작 메뉴가 숨겨져 있을 때: 좌우 방향키를 짧게 누르면 10초 탐색하고, 길게 누르면 탐색 위치가 연속으로 이동하며 모바일과 같은 작은 좌우 이동 시간 표시를 사용합니다. 길게 누르는 동안 점차 빨라지며, 영상 미리보기는 한 번에 하나만 요청하고 대기 중인 요청은 마지막 위치로 합칩니다. 손을 떼면 최종 위치를 확정하고 이전의 재생·일시정지 상태를 복원합니다. 실제 미리보기 속도는 서버와 영상 키프레임에 따라 달라질 수 있습니다.
- 확인·위아래 방향키는 조작 메뉴를 표시합니다. 메뉴를 연 확인 입력이 재생 버튼까지 누르지는 않습니다.
- 조작 메뉴가 보일 때: 방향키로 버튼·탐색 막대를 이동하고 확인으로 실행합니다. 뒤로 버튼은 메뉴를 먼저 닫고, 메뉴가 숨겨져 있으면 재생 화면을 나갑니다.
- 리모컨의 재생·일시정지·되감기·빨리감기 버튼과 이전·다음 영상 버튼도 지원합니다. 메뉴 버튼은 재생 설정을 엽니다.
- TV에서는 터치용 화면 잠금을 표시하지 않습니다. 자막 위치와 모양은 재생 설정에서 조절합니다.

TV 전용 레이아웃은 `layout-television`에서 선택하며, 모바일 재생 레이아웃은 기존 파일을 사용합니다. 실제 TV에서 서버 로그인·코덱·리모컨별 동작은 별도로 확인해야 합니다.

- MPV/FFmpeg가 영상·음성 디코딩, 탐색, 재생 속도와 재생 시계를 담당합니다.
- Shyni의 로그인·라이브러리·View 문맥·파일별 재생 티켓·오디오/자막 선택·이어보기·서버 진행률 저장을 사용합니다.
- 기기가 보고한 코덱에만 MediaCodec 하드웨어 디코딩을 사용하고, 지원하지 않는 포맷은 MPV 소프트웨어 디코딩으로 전환합니다. HEVC 10비트·AV1·VP9 등의 디코더를 포함합니다.
- 기기 RAM과 사용 가능한 메모리에 맞춰 읽기 캐시를 제한하고, 소프트웨어 디코더 스레드를 조정합니다. 디스크에 영상 캐시를 쌓지 않습니다.
- 재생/정지, 화면 맞춤·채움·늘림, 탐색·음량·밝기 제스처, 오디오·자막 트랙 선택, 속도 조절을 제공합니다.
- 자막은 기존 **Shyni Player**의 파서, 가로·세로 Canvas, 크기·색상·테두리·위치 조절을 사용합니다. 기본 제공 글꼴은 **시스템 기본** 하나이며, TTF/OTF 글꼴을 직접 추가할 수 있습니다.
- 가져온 글꼴은 앱 내부에 복사해 보관하며, 파일 하나당 20 MB까지 지원합니다. 원본 파일을 옮겨도 선택한 글꼴은 유지됩니다.
- 이전 버전의 내장 글꼴을 선택해 두었다면 시스템 기본으로 바뀝니다. 이미 가져온 사용자 글꼴과 선택은 유지됩니다.
- 내장 텍스트 자막은 MPV `sub-text`를 Shyni Canvas로 전달합니다. 외부 자막은 기존 파서와 재생 시계로 표시합니다. PGS/VobSub 등 이미지 자막은 MPV가 직접 표시합니다.
- 변환 재생에서는 서버가 내장 텍스트 자막을 VTT로 추출하고, 기존 자막 모양과 전체 영상의 시청 위치에 맞춰 표시합니다. 이미지 자막을 사용하려면 원본 재생이 필요할 수 있습니다.

세로쓰기는 일반 텍스트 자막에 적용합니다. 이미지 자막을 세로 텍스트로 바꾸거나, 원본 ASS의 애니메이션을 Shyni의 일반 텍스트 Canvas에 재현하는 기능은 포함하지 않습니다. DRM 보호 영상, 손상 파일, 서비스가 제한하는 영상의 재생을 보장할 수는 없습니다.

## 개발

Android 프로젝트는 `android/`에 있습니다. 기존 Shyni Player와 원본 서버는 수정하지 않았습니다. 공개 범위는 Android 앱이며, 초기 Windows 시제품과 로컬 검증 자료는 개발자의 작업 공간에만 보관합니다.

JDK 17, Android SDK 플랫폼 36, PowerShell, 네트워크 또는 기존 Gradle 의존성 캐시가 필요합니다. 먼저 고정된 공식 mpv-android 배포본에서 네이티브 라이브러리를 준비합니다. 설정 스크립트는 다운로드한 APK와 소스 아카이브의 SHA-256을 검사하며, 생성된 라이브러리와 다운로드 캐시는 Git에서 제외합니다.

```powershell
.\android\setup-mpv.ps1

# 자신의 JDK 17과 Android SDK 설치 경로를 지정합니다.
.\android\build.ps1 -JdkPath 'C:\path\to\jdk-17' -AndroidSdkPath 'C:\path\to\Android\Sdk' -Online
```

이미 준비된 캐시만 사용하려면 `setup-mpv.ps1 -Offline`을 실행하고, 빌드 명령에서 `-Online`을 생략합니다. `-WithDeviceTestApks`를 추가하면 기기용 테스트 APK도 만들며, 기본 빌드는 단위 테스트를 실행합니다. 결과 APK는 `android/app/build/outputs/apk/`에 생성됩니다. CPU별 APK는 Gradle의 `:app:assembleRelease -PshyniflexTargetAbi=arm64-v8a`로 빌드합니다. `armeabi-v7a`와 `x86_64`도 지원하며, 이 옵션을 생략하면 세 CPU를 포함한 통합 APK를 만듭니다. `Build-Android.cmd`도 동일한 빌드 인자를 받습니다.

첫 빌드에서는 개인 서명키를 `android/.local/`에 생성합니다. 이 디렉터리와 `local.properties`, 빌드 결과, 서버 자료, 계정 정보는 공개 업로드 대상에서 제외합니다. 직접 생성한 키는 기존 배포본의 서명과 다르므로 해당 APK 위에 업데이트 설치할 수 없습니다. 자신의 배포본 업데이트를 유지하려면 생성한 키를 안전하게 보관하세요.

## TV 자동 업데이트

기존 TV 테스트 앱은 [1.0.53 릴리스](https://github.com/bluemirr8520-lgtm/shyniflex/releases/tag/v1.0.53)의 `shyniflex-tv.apk`로 업데이트합니다. 버전은 1.0.53-test(빌드 54)이며 기존과 같은 `io.mirr.shyniflex.debug` 패키지·서명을 사용해 계정과 설정을 유지합니다. 휴대폰·태블릿·Android TV에서 사용할 수 있고, 정식 앱과는 별도로 설치됩니다.

TV 홈 오른쪽 위에 기기 설정에 맞춘 현재 시각을 표시합니다. 앱이 전면으로 돌아올 때 새 버전을 자동 확인하며, 정상 확인은 6시간, 연결 오류 후 재시도는 15분 간격으로 제한합니다. 새 APK는 자동으로 내려받고 파일 해시·패키지·버전·설치된 앱의 서명을 확인한 뒤 설치 화면을 제공합니다. 모바일 하단 **더보기 → 업데이트** 또는 TV 사이드바의 **업데이트**로 즉시 확인할 수도 있습니다. 최초 한 번 이 앱의 설치 허용이 필요하며, 설치는 Android 확인 화면에서 진행합니다. 영상 재생 도중 설치를 강제로 시작하지 않습니다.

다음 배포는 `versionCode`를 올리고 동일한 서명키로 APK를 빌드한 후 아래 스크립트로 공개합니다. 앱은 해당 저장소에 공개된 업데이트 정보에서 자기 패키지의 더 높은 버전만 사용합니다. 서명키나 GitHub 토큰을 저장소에 넣지 마세요. GitHub 인증은 로컬 Git 자격 증명 또는 `GH_TOKEN` 환경 변수를 사용합니다.

```powershell
.\android\publish-update.ps1 -Tag 'tv-1.0.16' -AndroidSdkPath 'C:\path\to\Android\Sdk' -CorrespondingSourcePath 'C:\path\to\shyniflex-corresponding-source.zip'
```

스크립트는 APK·업데이트 정보·전체 대응 소스·체크섬을 먼저 비공개 초안에 올린 뒤 릴리스를 공개합니다. 이미 공개된 릴리스는 덮어쓰지 않습니다. 네이티브 라이브러리를 바꾸지 않는 배포는 기존 대응 소스 묶음의 네이티브·JVM 아카이브를 보존하고 `app-source.zip`과 상위 소스 안내·체크섬을 현재 앱 소스로 갱신합니다.

PLEXMINI는 `plexmini-v<버전>` 태그를 사용합니다. 버전 코드와 버전 이름을 올리고, 빌드한 소스 커밋에 해당 태그를 푸시한 후 그 커밋에서 아래처럼 배포합니다. 스크립트가 APK의 패키지와 배포 서명을 확인하고 전용 업데이트 정보인 `plexmini-update.json`을 함께 게시합니다.

```powershell
.\android\publish-update.ps1 -Tag 'plexmini-v1.0.4' -ApkPath '.\outputs\PLEXMINI-1.0.4.apk' -CorrespondingSourcePath '.\outputs\PLEXMINI-1.0.4-corresponding-source.zip' -Notes 'PLEXMINI 자동 업데이트 지원'
```

### 새 서명으로 별도 설치하는 1.0.74

기존 1.0.67의 TV 재생 시작 충돌을 수정한 새 앱은 `io.mirr.shyniflex.renewed` 패키지로 설치됩니다. 기존 앱과 함께 사용할 수 있으며 새 앱에서는 다시 로그인해야 합니다. 앱은 별도 서명키를 사용합니다. 이후 같은 앱을 업데이트하려면 해당 서명키와 설정을 안전하게 보관해야 합니다. 빌드에는 `-PshyniflexApplicationId=io.mirr.shyniflex.renewed` 및 해당 키가 들어 있는 `-PshyniflexSigningRoot=<서명 설정 폴더>`를 사용합니다. 키와 비밀번호는 저장소나 릴리스에 올리지 마세요.

[새 앱 설치 파일과 대응 소스 받기](https://github.com/bluemirr8520-lgtm/shyniflex/releases/tag/v1.0.85-renewed). GitHub Actions의 수동 `Build renewed Android app`은 서명키와 설정을 암호화된 Actions 비밀변수로 등록한 후 사용할 수 있습니다. 이 작업은 서명된 APK 아티팩트를 생성하며 릴리스를 자동 게시하지는 않습니다. 배포할 때는 대응 소스와 업데이트 매니페스트도 함께 게시해야 합니다.
