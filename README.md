# shyniflex

MPV 기반의 **Android용 Shyni 서버 플레이어**입니다. 휴대폰·태블릿·Android TV에서 사용하며 Android 8.0 이상을 지원합니다. 첫 로그인 화면의 서버 주소는 빈칸이며 사용자가 직접 입력합니다.

공개 소스는 [GitHub shyniflex](https://github.com/bluemirr8520-lgtm/shyniflex)에서 제공합니다. Git에는 Android 앱 소스와 빌드 안내를 보관하며, 사용자 소유 앱 코드는 **GPL-3.0-or-later**로 배포합니다. APK와 전체 대응 소스 ZIP은 GitHub Release의 별도 파일로 배포합니다.

- [shyniflex 1.0.13 APK](https://github.com/bluemirr8520-lgtm/shyniflex/releases/download/v1.0.13/shyniflex-1.0.13.apk)
- [shyniflex 1.0.13 전체 대응 소스](https://github.com/bluemirr8520-lgtm/shyniflex/releases/download/v1.0.13/shyniflex-1.0.13-corresponding-source.zip)
- [v1.0.13 릴리스 페이지](https://github.com/bluemirr8520-lgtm/shyniflex/releases/tag/v1.0.13)

전체 대응 소스 ZIP에는 해당 앱 소스, MPV·FFmpeg 등 네이티브 의존 소스, 하위 모듈, Maven 런타임 라이브러리의 소스, 빌드 스크립트와 라이선스를 함께 담습니다. 복원 방법은 [네이티브 대응 소스 안내](docs/NATIVE-SOURCES.md)를 참고하세요.

## 설치와 사용

설치 파일은 위 APK 링크의 `shyniflex-1.0.13.apk`(빌드 14)입니다. 개발자의 로컬 배포본은 `outputs/shyniflex-1.0.13.apk`에 보관합니다. ARM64, ARMv7, x86_64 네이티브 라이브러리를 포함합니다. 기존 버전에서 업데이트 설치하면 로그인과 설정을 유지합니다.

1. APK를 Android 기기에 설치합니다.
2. Shyni 서버의 HTTPS 주소와 사용자 이름·비밀번호를 입력해 로그인합니다. 2단계 인증을 사용하는 경우 인증 코드를 입력합니다.
3. 라이브러리에서 영화 또는 회차를 선택해 재생합니다.
4. 재생 화면 **설정 → 자막 → 자막 모양 → 세로 쓰기**에서 세로 자막을 켭니다.
5. **설정 → 자막 → 자막 글꼴**에서 **시스템 기본** 또는 직접 가져온 글꼴을 고릅니다. **폰트 파일 추가**로 TTF/OTF 파일을 가져옵니다.
6. 자막을 길게 누른 뒤 끌면 위치가 바뀝니다. 손을 떼면 저장하고, 화면 밖으로는 벗어나지 않습니다. TV에서는 같은 설정의 **자막 위치** 메뉴를 사용합니다.

이어보기는 부분 시청을 끝낼 때 최종 위치 저장을 최대 4초 기다린 뒤 갱신하며, 늦게 저장이 완료돼도 홈을 다시 불러옵니다. 진행률 저장의 일시적인 통신 오류는 요청당 5초 한도로 최대 3번 시도합니다. 이어보기 조회가 실패하면 오류를 표시하고, 같은 서버·계정에서 여전히 접근 가능한 목록만 유지합니다. 로그인 변경·권한 거부·스포일러 잠금 뒤에는 이전 비공개 항목을 재사용하지 않습니다. 서버의 표시 기준은 그대로 적용됩니다. 기본 설정은 실제 시청 누적 1분 이상이며, 앞으로 건너뛴 위치만 길다고 등록되지는 않습니다. 앱 프로세스가 종료될 때까지 저장에 성공하지 못한 요청을 영구 보관하는 기능은 포함하지 않습니다.

작품 상세의 이어보기 대상이나 회차 시청 기록에서 서버가 회차 정체성 오류를 보내더라도, 접근이 허용된 시즌·회차 목록을 표시합니다. 조회에 실패한 시청 기록은 기존 상태를 유지하며, 다른 묶음에서 정상 조회한 기록은 반영합니다. 실제 시즌·회차 목록 조회와 재생 요청의 오류는 그대로 안내합니다.

저장된 로그인이 있으면 홈 화면을 먼저 표시하고 계정 검증과 스포일러 상태 조회를 병행합니다. 일반 이어보기·최근 추가 목록은 비공개 목록이나 선택 기능의 응답을 기다리지 않고, 확인된 라이브러리 범위에서 표시합니다. 홈을 불러오는 중에도 라이브러리 선택과 재생을 할 수 있습니다.

이어보기와 최근 추가 목록은 각 응답이 도착하는 대로 따로 표시합니다. 최근 추가 목록을 불러오는 동안에도 이어보기 카드를 선택할 수 있습니다. 이어보기 영역은 빈 기록·불러오는 중·오류를 구분해 표시하고, 오류에는 다시 시도 버튼을 제공합니다. 잘못된 응답 구조를 빈 기록으로 간주하지 않으며, 같은 계정의 기존 목록만 권한 범위 안에서 유지합니다.

홈 이어보기는 Plezy의 제목·회차 표시와 재생 버튼 구성을 참고합니다. 상단에는 선택한 작품의 배경 이미지·제목·소개를 표시합니다. 소개 영역은 휴대폰에서 240dp, 넓은 화면에서 화면 높이에 따라 180~240dp로 배치해 아래 목록을 가깝게 둡니다. 목록의 초점을 옮기면 상단 정보와 **흰색 이어보기 버튼**의 대상이 함께 바뀝니다. 버튼에는 실제 시청 위치의 진행률과 남은 시간을 분 단위로 올림해 표시하며, 재생 시간 정보가 없으면 남은 시간을 추측하지 않습니다.

이어보기의 회차 목록과 영화·회차 혼합 목록은 **16:9 가로 썸네일**, 영화만 있는 목록은 **2:3 세로 포스터**를 사용합니다. 서버가 제공한 회차 스틸(`thumb_url`), 작품 포스터(`poster_url`), 배경 이미지(`art_url`)를 각각 보존하며, 제공하지 않은 이미지는 있는 이미지로 대체합니다. 카드 아래에는 작품명과 시즌·회차·회차 제목을 표시합니다. 카드나 흰색 버튼을 누르면 해당 작품을 시청하던 위치에서 바로 재생하고, 카드를 길게 누르면 시청 상태를 변경합니다. 목록은 끝이 있는 가로 목록이며 자동으로 넘어가거나 무한 순환하지 않습니다. 최근 추가됨 목록과 스포일러 잠금에 따른 표시 규칙은 유지합니다.

홈·라이브러리·회차 목록의 포스터를 **길게 누르면 보았음 / 보지 않음**을 선택합니다. 시리즈·시즌은 **모든 회차 보았음 / 모든 회차 보지 않음**으로 표시하며, 접근이 허용된 회차를 한 번에 최대 500개까지 변경합니다. 500개를 초과하면 변경을 시작하지 않습니다. 일부 회차 변경에 실패하면 성공한 회차 수를 안내하며, 이미 성공한 변경은 서버에 남습니다. 시리즈·시즌의 전체 시청 표시는 모든 변경이 성공한 뒤 현재 앱 세션에서 유지합니다.

확정된 재생 위치가 **전체 영상 길이의 95% 이상**이면 서버에 보았음으로 저장하고 포스터 표시를 갱신합니다. 변환 재생도 원본 전체 영상의 위치를 기준으로 하며, 손을 떼기 전 탐색 중간 위치는 완료로 처리하지 않습니다. MPV의 실제 종료 상태를 확인하면 서버 저장 응답을 기다리지 않고 재생창을 닫아 **홈으로 돌아갑니다**. 완료 기록은 별도 작업에서 저장하고, 늦게 저장돼도 홈을 다시 갱신합니다. 95% 지점에서 일시정지한 영상과 재생 오류는 창을 유지합니다. 직접 뒤로 나간 경우에는 이전에 열었던 화면으로 돌아갑니다.

라이브러리 선택 화면의 **스포일러 라이브러리 열기**에서 서버의 PIN을 입력합니다. 현재 로그인한 Shyni 서버에 등록되고 접근이 허용된 비공개 영화·시리즈 라이브러리(View)를 표시하며, 기존 계정 로그인과 서버의 접근 권한이 필요합니다. **스포일러 라이브러리 잠금**으로 다시 잠글 수 있습니다. PIN과 잠금 해제 권한은 앱에 저장하지 않으며, 권한은 앱 메모리에서만 유지됩니다. 앱이 백그라운드로 전환되거나 서버가 정한 시간이 지나면 다시 잠기므로 PIN을 다시 입력해야 합니다.

스포일러 라이브러리의 **이어보기는 잠금을 해제한 동안에만** 표시합니다. 다시 잠그거나 권한이 만료되거나 앱이 백그라운드로 전환되면 비공개 포스터·상단 작품 정보·열려 있던 시청 상태 선택창을 즉시 숨기고, 일반 라이브러리의 이어보기는 유지합니다. 다시 잠금을 해제하면 서버의 시청 기록을 새로 불러옵니다. 잠금은 서버의 시청 기록을 삭제하지 않습니다. 공개·비공개 목록의 항목이 섞여 오면 확인된 라이브러리에 맞게 걸러내며, 같은 작품의 중복 응답은 한 번만 표시합니다.

스킵은 두 번 탭 또는 가로 스와이프로 조작합니다. 뒤로 이동하면 영상 왼쪽에 **10초<**, 앞으로 이동하면 오른쪽에 **10초>**와 같은 작은 표시가 나타납니다. 표시는 시스템 바와 화면 잘림 영역의 안쪽에 배치합니다. 스와이프 중에는 시작 위치부터 실제로 이동한 시간을 표시하고, 영상의 처음·끝에서 이동이 제한되면 그 시간에 맞춰 표시합니다. 탐색용 중앙 시계·진행 막대는 표시하지 않습니다. 밝기·음량은 기존 중앙 표시를 사용합니다. 스킵·밝기·음량·자막 이동 제스처 중에는 컨트롤이 숨겨집니다. 화면을 한 번 탭하면 컨트롤을 표시하거나 숨깁니다. 상단 **잠금** 버튼도 컨트롤과 함께 표시됩니다. 잠긴 화면을 한 번 탭하면 **해제** 버튼이 나타납니다.

하단 **이전 영상·다음 영상** 아이콘은 **현재 파일이 바로 들어 있는 실제 폴더가 같은 영상**으로만 이동합니다. 서버가 제공한 파일 경로로 같은 폴더임이 확인되어야 하며, 이동 대상이나 경로를 확인할 수 없으면 해당 아이콘을 비활성화합니다. 같은 폴더 안에서 영화는 라이브러리·검색 목록 순서, 시리즈는 시즌·회차 순서를 기준으로 이동하며, 한 작품에 묶인 파일은 서버의 파일 순서를 우선합니다. 끝에서 처음으로 순환하지 않습니다. 이동한 영상은 **0초부터** 시작하고, 선택한 배속·변환·자막 모양 설정과 일시정지 상태를 유지합니다.

서버가 인트로·크레딧의 시작·끝 구간 정보를 제공한 영상에서는 해당 구간에 **인트로 건너뛰기** 또는 **크레딧 건너뛰기** 버튼이 나타납니다. 누르면 그 구간의 끝으로 이동하며 일시정지 상태를 유지합니다. 이 기능에는 서버의 구간 마커가 필요합니다.

하단 **배속** 버튼에서 0.25~4배속을 선택하며, 선택한 속도는 다음 재생에도 유지됩니다. **변환** 버튼을 누르면 **변환 (데이터 절약)** 메뉴에서 **원본 (변환 안 함)** 또는 **1080p·720p·480p 변환**을 고릅니다. 변환은 현재 재생 중인 같은 파일을 서버에서 처리하며, 시청 위치와 일시정지 상태를 유지합니다. 비트레이트는 서버가 해당 해상도에 맞춰 결정하므로 실제 데이터 사용량은 원본과 서버 설정에 따라 달라집니다. 서버에 영상 인코더가 있어야 하고 계정의 변환 권한이 필요합니다. 변환은 **설정 → 영상 → 변환**, 배속은 **설정 → 재생 → 배속**에서도 조절할 수 있습니다.

암호와 일회용 인증 코드는 저장하지 않습니다. 로그인 세션만 Android Keystore를 이용해 암호화해 저장합니다.

재생 준비 오류에는 재생 방식 확인·티켓 발급·자막 정보·이어보기 위치 조회 중 실패한 단계를 표시합니다. 서버가 재생을 허용한 파일은 진행률의 특정 회차 식별 오류 때문에 폐기하지 않고 카드에 남아 있는 시청 위치로 시작합니다. 서버의 회차 번호가 누락된 경우에는 목록에서 받은 실제 파일 ID와 같은 라이브러리 문맥으로 정식 스트림 티켓을 요청해 원본 재생을 시도합니다. 이 요청에도 서버의 파일 소속·시청 권한·동시 스트림 검사가 적용됩니다.

## 재생과 자막

- MPV/FFmpeg가 영상·음성 디코딩, 탐색, 재생 속도와 재생 시계를 담당합니다.
- Shyni의 로그인·라이브러리·View 문맥·파일별 재생 티켓·오디오/자막 선택·이어보기·서버 진행률 저장을 사용합니다.
- 기기가 보고한 코덱에만 MediaCodec 하드웨어 디코딩을 사용하고, 지원하지 않는 포맷은 MPV 소프트웨어 디코딩으로 전환합니다. HEVC 10비트·AV1·VP9 등의 디코더를 포함합니다.
- 기기 RAM과 사용 가능한 메모리에 맞춰 읽기 캐시를 제한하고, 소프트웨어 디코더 스레드를 조정합니다. 디스크에 영상 캐시를 쌓지 않습니다.
- 재생/정지, 화면 맞춤·채움·늘림, 탐색·음량·밝기 제스처, 오디오·자막 트랙 선택, 속도 조절을 제공합니다.
- 자막은 기존 **Shyni Player**의 파서, 가로·세로 Canvas, 크기·색상·테두리·위치 조절을 사용합니다. 기본 제공 글꼴은 **시스템 기본** 하나이며, TTF/OTF 글꼴을 직접 추가할 수 있습니다.
- 가져온 글꼴은 앱 내부에 복사해 보관하며, 파일 하나당 20 MB까지 지원합니다. 원본 파일을 옮겨도 선택한 글꼴은 유지됩니다.
- 이전 버전의 내장 글꼴을 선택해 두었다면 시스템 기본으로 바뀝니다. 이미 가져온 사용자 글꼴과 선택은 유지됩니다.
- 내장 텍스트 자막은 MPV `sub-text`를 Shyni Canvas로 전달합니다. 외부 자막은 기존 파서와 재생 시계로 표시합니다. PGS/VobSub 등 이미지 자막은 MPV가 직접 표시합니다.
- 변환 재생에서는 서버가 내장 텍스트 자막을 VTT로 추출하고, 기존 자막 모양과 전체 영상의 시청 위치에 맞춰 표시합니다. 이미지 자막을 사용하려면 원본 재생이 필요할 수 있습니다.

세로쓰기는 일반 텍스트 자막에 적용합니다. 이미지 자막을 세로 텍스트로 바꾸거나, 원본 ASS의 애니메이션을 Shyni의 일반 텍스트 Canvas에 재현하는 기능은 포함하지 않습니다. DRM 보호 영상, 손상 파일, 서비스가 제한하는 영상의 재생을 보장할 수는 없습니다.

## 개발

Android 프로젝트는 `android/`에 있습니다. 기존 Shyni Player와 원본 서버는 수정하지 않았습니다. 공개 범위는 Android 앱이며, 초기 Windows 시제품과 로컬 검증 자료는 개발자의 작업 공간에만 보관합니다.

JDK 17, Android SDK 플랫폼 36, PowerShell, 네트워크 또는 기존 Gradle 의존성 캐시가 필요합니다. 먼저 고정된 공식 mpv-android 배포본에서 네이티브 라이브러리를 준비합니다. 설정 스크립트는 다운로드한 APK와 소스 아카이브의 SHA-256을 검사하며, 생성된 라이브러리와 다운로드 캐시는 Git에서 제외합니다.

```powershell
.\android\setup-mpv.ps1

# 자신의 JDK 17과 Android SDK 설치 경로를 지정합니다.
.\android\build.ps1 -JdkPath 'C:\path\to\jdk-17' -AndroidSdkPath 'C:\path\to\Android\Sdk' -Online
```

이미 준비된 캐시만 사용하려면 `setup-mpv.ps1 -Offline`을 실행하고, 빌드 명령에서 `-Online`을 생략합니다. `-WithDeviceTestApks`를 추가하면 기기용 테스트 APK도 만들며, 기본 빌드는 단위 테스트를 실행합니다. 결과 APK는 `android/app/build/outputs/apk/`에 생성됩니다. `Build-Android.cmd`도 동일한 빌드 인자를 받습니다.

첫 빌드에서는 개인 서명키를 `android/.local/`에 생성합니다. 이 디렉터리와 `local.properties`, 빌드 결과, 서버 자료, 계정 정보는 공개 업로드 대상에서 제외합니다. 직접 생성한 키는 기존 배포본의 서명과 다르므로 해당 APK 위에 업데이트 설치할 수 없습니다. 자신의 배포본 업데이트를 유지하려면 생성한 키를 안전하게 보관하세요.

프로젝트 라이선스는 [LICENSE](LICENSE), 구성 요소의 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), 네이티브 소스 복원과 빌드 환경은 [docs/NATIVE-SOURCES.md](docs/NATIVE-SOURCES.md)를 참고하세요. 일반 앱 빌드는 고정된 공식 네이티브 바이너리를 재사용하며, 네이티브 소스에서의 별도 빌드는 Linux 또는 macOS 환경을 사용합니다.
